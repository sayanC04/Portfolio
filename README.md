# Personal Portfolio Website

A responsive and dynamic personal portfolio website designed to showcase projects, skills, and professional experience. Built with a focus on clean aesthetics and smooth user interactions.

## 🚀 Features

- **Responsive Design:** Fully responsive layout that works seamlessly across desktop, tablet, and mobile devices.
- **Modern UI/UX:** Clean, dark-themed aesthetic with smooth scrolling and hover animations.
- **Dynamic Content:** Typing effects and interactive elements built with Vanilla JavaScript.
- **Project Showcase:** Dedicated sections for highlighting technical projects and achievements.
- **Contact Integration:** Easy-to-use contact links and downloadable resume.

## 💻 Technologies Used

- **HTML5:** Semantic structure and content.
- **CSS3:** Custom styling, flexbox/grid layouts, and animations.
- **Vanilla JavaScript:** DOM manipulation, event handling, and interactive features without heavy frameworks.

## 🛠️ Local Setup & Development

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd YOUR_REPOSITORY_NAME
   ```

3. **Open the project:**
   Simply open the `index.html` file in any modern web browser. No build steps or local servers are required!
   
   *(Alternatively, use the "Live Server" extension in VS Code for hot-reloading during development).*
